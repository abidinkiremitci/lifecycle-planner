# Day 6 — Saturday (2026-08-22)

## Running — Return (Easy)

First run back after the back injury week. Keep it easy — this is a retest, not a performance effort.

### Warm-up (5 min)
- 5 min easy walk + leg swings, ankle rolls, calf raises

### Main Run (25 min)
- **5 km @ ~5:45–6:00/km**, zone 2 effort (fully conversational)
- RPE 5–6 — if back tightens at any point, walk immediately; do not push through back pain while running
- Indoor alternative (if back is uncertain): 25 min easy row @ ≤2:40/500 m or 30 min easy walk

### Cool-down (5 min)
- 5 min easy walk
- Standing hip flexor stretch 45 s/side
- Seated hamstring fold 45 s/side
- Wall calf stretch 45 s/side
